# Discourse Phosphor Duotone Icons

[ENGLISH](README.md) | **ESPAÑOL**

Componente de tema que permite a Discourse usar los iconos duotone de [Phosphor](https://phosphoricons.com/), además de algunos extras propios de la comunidad. Fork de [discourse/discourse-phosphor-duotone-icons](https://github.com/discourse/discourse-phosphor-duotone-icons).

## Instalación

Admin → Personalizar → Temas → Componentes → Instalar → Desde un repositorio git, con la URL de este repo. Luego añade el componente a los temas que deban usarlo.

Los iconos se referencian por nombre con el prefijo `ph-dt-` (por ejemplo `ph-dt-anchor`). La lista permitida está en `about.json` (`modifiers.svg_icons`) y el sprite en `assets/icons-sprite.svg`.
